## 用大白话看他的核心思想

下面 8 条是他反复出现的思考顺序，不是某一天的买卖指令。

1. 他是更高周期的波段交易者，目标是抓住一段大行情，不是在 5 分钟图上找刺激。他自己说主要按时间而不是按精确价格交易，能接受利润来回波动。https://x.com/KillaXBT/status/2119466979287576759
2. 先看眼前的价格结构和走势确认，再看季节性、分形和历史规律。规律如果没有被当下走势验证，他就认为成功率会下降；他也认为四年一轮不会永远重复，比特币不会永远在四季度见底或见顶。https://x.com/KillaXBT/status/2119466979287576759
3. 仓位是分层的：一部分现货长期拿着，一部分核心波段多，一部分更高价位的延续多，再加一笔更高杠杆、更小的试探多。大方向有把握时，他会用已经浮盈的仓位去开隔离的高风险仓，用来加重暴露。https://x.com/KillaXBT/status/2117997608945754531
4. 他认为自己处在牛市或趋势向上时，默认不轻易做空，更常做的是「扫出来的低点再买」。他的原话大意是：趋势行情里，笨多头往往比聪明空头更好过。https://x.com/KillaXBT/status/2118305287148818895 · https://x.com/KillaXBT/status/2118673211814457539
5. 开仓和加仓之前，他会先写下失效条件。核心长线多、延续多、现货，三套止损不一样。如果「底部已在」被证伪，他写过最坏情况：杠杆仓被打掉后，把现货卖掉，再集中做成一笔 2 倍多。https://x.com/KillaXBT/status/2118675976070578387 · https://x.com/KillaXBT/status/2119803651858280701
6. 他认为市场涨跌很多时候是在寻找对手盘的止损，新闻往往是事后找的理由，不是先有新闻才有波动。https://x.com/KillaXBT/status/2119041173511635290
7. 宏观上他常看美国中期选举后的去风险、物价数据、美联储议息、油价，以及比特币相对美股是否跟得上。这些是他解释环境的时钟，不是自动买卖开关。https://x.com/KillaXBT/status/2118375157630734524 · https://x.com/KillaXBT/status/2119872551669092526
8. 他认错过。写得最清楚的一次是 2026-05-05：空单开早了，没有等价格真正跌回区间里再确认，等于没遵守自己预先写好的更高概率做法。另一次是 2026-10-30：他常用的议息前后时间枢纽这次没有兑现。https://x.com/KillaXBT/status/2051695424365289617 · https://x.com/KillaXBT/status/2116229046761660526
